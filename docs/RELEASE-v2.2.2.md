# v2.2.2 · 私人 FM 一次 50 首 + 开机自启

**一句话**：私人 FM 现在一次给你 50 首、能看列表随便挑；设置里也能一键开机自启了。

## 私人 FM

- **一次 50 首**：进入私人 FM 自动拉满 50 首并显示成列表，不再是「点一次播一首」。
- **边拉边显示**：接口一次只给 3 首，现在分批加载，先出前 12 首，剩下的陆续补上，大约 6 秒拉满 50 首。
- **列表操作**：播放全部、点任意一首播放、下一首、加载更多（再追加 50 首）。
- **自动续播**：一首播完自动下一首，列表放到头会自动再拉一批。
- **去重**：多次请求按歌曲 ID 去重，同一首歌不会在列表里出现两次。

## 开机自启

- 设置 → 启动与系统 → 开机自启，打开后登录系统即自动启动。
- 开关即时生效，写入系统登录项；也可以随时在系统「启动应用」里关闭。
- 便携版同样可用（跟随当前 exe 路径）。

## 顺手修的

- 私人 FM 歌名被全局样式截断（只显示前几个字），改用独立的样式类，现在歌名完整显示。

## 验证

- 私人 FM：50 首加载耗时约 6 秒，列表无重复；播放全部 / 单曲 / 下一首 / 加载更多均正常。
- 三种布局（经典 / 沉浸 / 杂志）× 全部视图冒烟通过，无控制台报错。
- 开机自启：开关 → 系统登录项写入 → 关闭后移除，实测通过。
- 在线收音机：国内电台继续正常播放。
