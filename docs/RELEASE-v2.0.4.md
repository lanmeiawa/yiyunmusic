# yiyunmusic v2.0.4 更新说明

> 这次更新，你能感受到什么？—— 两件事，都用大白话讲。

## 1. Cookie 不再明文躺在配置文件里

以前登录凭证（Cookie）是以明文写进本地配置文件的。用文本编辑器打开 `yiyun-store.json`，就能直接看到你的登录态。

这次我们把它**加密存储**了：

- 配置文件里不再出现明文 Cookie，打开只有一串看不懂的密文
- 加密采用 AES-256-GCM，每次写入都用新的随机因子，同样的登录态每次存的密文都不一样
- **升级不掉登录**：旧版本留下来的明文凭证，启动时会自动转成密文，你不用重新扫码
- 应用内部还是照常用明文凭证调接口，所以听歌、歌单、收藏这些功能一点没变，也不会变慢

先说清楚边界：这是**轻度加密**，目的是挡住"随手打开配置文件"和"写个脚本扫目录"这类情况。桌面应用把密钥放在本地，专业逆向总能翻出来；真要做到系统级保护得上操作系统钥匙串，对一个第三方客户端来说收益不大。所以这一版做到的是"不再明文、不被简单逆向"，而不是"绝对无法破解"。

> 顺带说明：这里加密的是网易云登录凭证。不管你用网易云 App 扫码还是微信扫码登录，最终落到本地的都是同一个 Cookie，所以两种登录方式都受保护。

## 2. Windows 和 Linux 继续同一个版本

这一版仍然是 **Windows + Linux 一个发布页、一个版本号**：进去按系统挑安装包就行，不用再分辨哪个是给自己用的。
