# yiyunmusic v2.0.2 更新说明

> 这次更新，你能感受到什么？—— 六件事，都用大白话讲。

## 1. 加歌单、收藏不再失败

以前想把一首歌「加入歌单」或点红心「收藏」，经常会报错失败，这是从头到尾最烦人的一个 bug。

这次彻底修好了：点一下，就成功。加重复了也会明确告诉你「已在歌单中」，不会再莫名其妙报错。

## 2. 本地歌曲也能直接播

打开任意本地音频文件（mp3 / flac / wav / m4a 等）就能直接播放。

更省心的是，它会**自动**找到同目录下同名的歌词文件（`.lrc`）和封面图——歌词、封面都不用你自己去配。

## 3. 所有操作更稳了

以前网络一抖、接口一抽风，就报错。现在应用会**自动重试**，还给每个请求加了超时兜底，不会动不动就卡住或报错。

## 4. 低分辨率屏幕不挤了

小屏幕上，左侧账号头像和歌单列表之前会被压扁、显示不全。现在修好了，头像完整、歌单正常滚动。

## 5. 首次启动多了一段说明

第一次打开会先看到一段简洁的免责声明（第三方客户端、依赖非公开接口、请支持正版），点「同意」才进入。这是对你也对项目负责。

## 6. 产品有了明确方向：专注「动态歌词」

这一版开始，我们把定位收窄成一句话——**把动态歌词做到极致**。逐字卡拉OK扫光、桌面歌词悬浮窗、歌词搜歌、本地歌词识别，这些都是主角；其余从简。
