# yiyunmusic v2.1.0 更新说明

> 这次是个中版本：三件大事，都用大白话讲。

## 1. 三种界面布局，设置里一键切换

以前界面只有一种样子。这次给了**三种整体布局**，在「个性化设置 → 界面布局」里点一下就切：

- **经典**：熟悉的左栏 + 主区 + 底栏，最稳妥
- **沉浸**：内容区更宽、留白更大、边框更弱，封面和歌词更突出
- **杂志**：双栏卡片流 + 大圆角封面，像在翻一本音乐杂志

切换立即生效，不用重启。

## 2. 在线收音机：收听全球电台

新增「在线收音机」，可以搜全世界网络电台。

- **数据源用 Radio Browser**：免费开源、公共数据，**不需要申请任何 API key**，也不用你花钱
- 四种找台方式：热门榜、按国家、按风格、按名字搜
- 点一下就播，走了本地代理，不会被跨域问题卡住
- 点播放会给电台热度 +1，帮这个公益项目把数据维护得更好

> 说明：这是网络电台流，和本地调频收音机不是一回事；音源由各电台提供，稳定性取决于对方服务器。

## 3. 收音机实时转文字（本地离线，不联网）

听外语台或新闻台时，可以把语音**实时转成文字**，像歌词一样一条条显示出来。

- 引擎用 **sherpa-onnx**（Apache-2.0 开源）+ SenseVoice 多语言模型，支持中英日韩粤
- **全程在本地跑**，不上传音频、不联网、不花钱
- 模型约 230MB，两种拿到方式：
  - **Windows 安装时**会问你要不要装模型——选「是」直接从安装包解压（快、不看网速）；选「否」跳过
  - 或者在「个性化设置 → 收音机语音转文字模型」里下载（走国内镜像，支持断点续传）
- 开收音机后点「实时转文字」即可，每几秒识别一段追加显示

> 老实说：模型会占约 230MB 磁盘，识别时约占一个 CPU 核的三分之一。嫌大或网速慢就先跳过，之后随时能装。
