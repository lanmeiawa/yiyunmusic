# v2.2.6 · 封面不跳了，设置也少了一个开关

**一句话**：歌词页左上角那张专辑封面不再自己转、也不再一跳一跳；顺手删掉了没什么用的「侧边栏紧凑模式」。

## 你能感受到的变化

- **封面稳住了**：播放时，歌词页的封面原本会一直转，方形的专辑图在圆框里转，四角被反复切掉又露出来，看着像在抽搐。现在它就是一张安安静静的封面，和播放条、歌单里的封面一致。
- **点封面能进歌词页**：播放条最左边那张封面现在可以点，点一下直接打开歌词页；没在播放时会带你去「发现音乐」。
- **设置更清爽**：「侧边栏紧凑模式」这个开关删掉了。它和「沉浸」布局的侧栏行为重叠，开了之后还得靠鼠标悬停才展开，实际很少有人用得上。
- **升级无感**：之前开过紧凑模式的话，升级后侧栏会回到正常宽度，不用再去设置里改回来。

## 关于那个「转圈封面」

原来的写法是把正方形的专辑图放进圆形框里旋转。方形图转到 45° 时，四个角会被圆框切掉；转回 0° 又露出来，一秒钟里轮廓反复变形，看起来就像封面在乱跳。

这次直接把旋转去掉了：封面保持静态方图 + 圆角，和播放条、歌单列表的展示方式统一。专辑封面本来就是一张静态图片，不转反而更耐看，也不会再有任何形变。

## 验证

- 播放中连续采样 10 秒：封面位置与尺寸恒为 52×52、图片无旋转、无位移
- 播放条封面点击 → 歌词页；未播放时点击 → 发现音乐，均无报错
- 设置页「界面布局」卡片：只剩 经典 / 沉浸 / 杂志 + 显示歌词翻译，无残留空行
- 用旧配置（`sidebarCollapsed: true`）启动：侧栏仍为正常宽度 212px，没有被折叠
- 三种布局 × 全部视图冒烟通过，**0 条控制台报错**
