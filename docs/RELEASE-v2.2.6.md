# v2.2.6 · 封面不跳了，歌词也更跟手了

**一句话**：歌词页的封面不再自己转、也不再一跳一跳；歌词重新对上播放进度，后半段不会提前“失踪”；顺手删掉了没什么用的「侧边栏紧凑模式」。

## 你能感受到的变化

- **封面稳住了**：播放时，歌词页的封面原本会一直转，方形的专辑图在圆框里转，四角被反复切掉又露出来，看着像在抽搐。现在它就是一张安安静静的封面，和播放条、歌单里的封面一致。
- **点封面能进歌词页**：播放条最左边那张封面现在可以点，点一下直接打开歌词页；没在播放时会带你去「发现音乐」。
- **点歌曲封面不再往下跳**：歌曲列表里的封面，鼠标移上去会往下坠半个身位（18px）——这不是动画效果，是 hover 样式把原有的居中位移覆盖掉了。现在只放大一点点，位置纹丝不动。
- **歌词立刻对上进度**：进入歌词页、切歌、从别的页面返回，都会直接对准当前这一句，不再从顶部慢慢滚过去；高亮也不会“空一段时间才亮”。
- **后半段歌词不再“失踪”**：有些歌词文件里混着只有时间戳、没有文字的空行，以前会被渲染成一片「♪」，还会被当成间奏，让页面提前跳进“等待”状态，看着像后半段歌词没了。现在这些空行会被过滤掉，最后一句也会一直亮着。
- **设置更清爽**：「侧边栏紧凑模式」这个开关删掉了。它和「沉浸」布局的侧栏行为重叠，开了之后还得靠鼠标悬停才展开，实际很少有人用得上。
- **升级无感**：之前开过紧凑模式的话，升级后侧栏会回到正常宽度，不用再去设置里改回来。

## 关于那个「转圈封面」

原来的写法是把正方形的专辑图放进圆形框里旋转。方形图转到 45° 时，四个角会被圆框切掉；转回 0° 又露出来，一秒钟里轮廓反复变形，看起来就像封面在乱跳。

这次直接把旋转去掉了：封面保持静态方图 + 圆角，和播放条、歌单列表的展示方式统一。专辑封面本来就是一张静态图片，不转反而更耐看，也不会再有任何形变。

## 歌词为什么之前会“慢半拍”

两个独立的小问题叠在一起：

1. **页面切换时高亮被清空**：切歌重置的 effect 排在“同步当前句”之后，刚算好的高亮立刻被重置成“无”，必须等下一句歌词才开始亮——看起来就像等了一两秒才校对。
2. **首次进入从顶部滚下来**：进入歌词页时滚动位置是 0，再平滑滚到当前句，距离长的时候要一两秒。

现在：重置先执行、同步紧跟其后；首次进入/切歌/页面返回都直接“瞬移”到当前句，只有相邻两句之间才用平滑滚动。

## 验证

- 播放中连续采样 10 秒：封面位置与尺寸恒为 52×52、图片无旋转、无位移
- 鼠标悬停歌曲列表封面：位置不变（仅 1.05 倍缩放，上下各扩 0.9px），移开完全复原
- 从 60 秒处进入歌词页：80ms 内高亮 + 滚动位置全部到位（原来要 1–2 秒）
- 切到其他页面再返回：80ms 内回到当前句，不需要等下一句
- 播到 92%、末尾前 3 秒：高亮停在最后一句，最后一行仍在可视区域内，不再出现整页空白
- 设置页「界面布局」卡片：只剩 经典 / 沉浸 / 杂志 + 显示歌词翻译，无残留空行
- 用旧配置（`sidebarCollapsed: true`）启动：侧栏仍为正常宽度 212px，没有被折叠
- 三种布局 × 全部视图冒烟通过，**0 条控制台报错**
