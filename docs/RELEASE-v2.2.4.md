# v2.2.4 · 动态歌词：间奏会停，切歌不串词

**一句话**：间奏时歌词不再傻挂着上一句，快速切歌也不会再显示上一首的歌词。

## 修了什么

**1. 间奏没有「停顿」**
以前只有在逐字歌词（klyric）里才能判断一句唱完，普通歌词会一直挂着上一句，间奏十几秒也纹丝不动。现在普通歌词也会按字数估算这句唱完的时间，只要离下一句有明显空档（超过 2.2 秒），就取消高亮——间奏、尾奏、前奏都能看出「停」下来了。

**2. 有时歌词对不上**
快速切歌时，上一首的歌词请求可能比新的晚返回，把新歌歌词覆盖掉，看起来就像「歌词不匹配」。现在给每次歌词请求编号，只接受最后一次的结果；本地音乐的内嵌歌词也优先，不会被在线结果抢走。

**3. 本地歌曲**
本地文件自带歌词时，会丢弃还在路上的在线歌词请求，避免刚显示就变掉。

## 验证

- 间奏判定做了 8 组单元测试（正常换句 / 长间奏 / 逐字歌词 / 最后一句 / 空行），全部通过。
- 实际播放验证：逐句高亮正常，间奏时间点高亮行数为 0，下一句开始后恢复高亮。
- 快速连切 3 首：7 秒与 11 秒两次读取歌词完全一致，且与当前歌曲对得上。
- 三种布局 × 全部视图冒烟通过，无控制台报错。
