# yiyunmusic v2.1.1 更新说明

> 小版本，修三个问题，都用大白话讲。

## 1. 部分电台播不了 —— 修好了

之前有些网络电台一点播放就失败。原因是我们的本地代理给所有音频都带了网易云的 Referer，很多电台把这种请求当成盗链直接拒绝。

这次改成：**电台流直连原始地址**（成功率最高），只有你开启「实时转文字」时才走本地代理（转写需要同源音频）。该拦截的没有了，能听的电台更多了。

## 2. 模型下载失败 —— 修好了

之前在设置里点下载语音模型，很可能一直失败。原因是代码里一个超时参数写成了 0，等于"立即超时"，请求刚发出去就被掐断。

这次修好了，还加了：

- **多镜像自动切换**：hf-mirror 不行自动换 Hugging Face 官方
- **断点续传**：网速慢或中途断了，下次接着下，不用从头来
- **进度显示**：实时看到下载百分比

## 3. 安装包不再塞模型，改问你要不要下载

v2.1.0 把 230MB 模型打进了安装包，包一下涨到 270MB+。这次改回轻量：

- **安装包恢复小体积**（约 110MB）
- 安装时会问你要不要下载模型：选「是」首次启动自动下（多镜像+断点续传），选「否」跳过
- 之后随时能在设置里下载/删除

## 4. UI 布局真正的整体改变

之前的三种布局只是调了调宽度，变化不明显。这次重做成**三种完全不同的界面结构**：

- **经典**：左边栏 + 主区 + 底栏，熟悉的样子
- **沉浸**：侧栏收成一条图标，内容居中大卡片、顶栏透明、播放器悬浮，像在用一个专注播放的播放器
- **杂志**：侧栏变成顶部横向导航，主区全宽大图卡片流，像翻一本音乐杂志

在「个性化设置 → 界面布局」切换，整个界面立刻变样。
