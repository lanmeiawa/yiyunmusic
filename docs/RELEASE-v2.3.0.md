# yiyunmusic v2.3.0 · 这次更新，你能感受到什么？

**一句话**：打开更快了——点开图标到看见界面，时间差不多砍掉一半；顺手清掉了一批没人用的代码，功能一个没少。

---

## 一、启动快了一倍

以前的启动流程里，有一件事特别亏：**程序一启动，先把整个网易云接口库（上百个模块）全加载一遍**，然后才去画窗口。你看到的「点了图标，等一会儿才出界面」，有一大半耗在这里。

这次把它改成「用到才加载」：窗口先出来，接口在你开始浏览时才在后台准备好。

实测（同一台机器，从双击到窗口出现）：

| | 之前 | 现在 |
|---|---|---|
| 启动到窗口显示 | 约 0.98 秒 | **约 0.40 秒** |

另外几处一起收紧了：

- **首屏只加载首屏要用的界面**：发现页、播放条、侧栏先加载，设置页、歌词页、搜索页等在你空闲时才悄悄预热。首次加载的脚本从 551KB 降到 **176KB**，切换页面仍然是一点就到。
- **桌面歌词用独立入口**：以前开桌面歌词，那个 640×150 的小窗口也要把整个应用（含所有页面、可视化、设置页）解析一遍；现在它只加载歌词本身，**11KB**。
- **托盘、图标不再抢启动**：托盘改成窗口出现后再创建；图标从 1.6MB 原图换成预生成的小图，少两次大图解码。

## 二、用起来更顺一点

- 搜索时切换「专辑 / 听书 / 歌词」分区，以前每次都会让整个界面重算一遍（哪怕没有地方显示这个状态），现在不会了。
- 队列、搜索结果、电台等几处已经不用的状态被移除，少了一些无意义的重绘。
- 移除了一个从未被使用的依赖（electron-store），安装包更干净。

## 三、清理与修复

- 删掉了 20 多处没人调用的代码：两个图标组件、一个图片降级函数、若干未使用的变量/导入/样式（约 6KB CSS）。
- 顺手修了三处潜在报错：
  - 每日推荐加载失败时，提示语会抛错（点了没反应）；
  - 播放条音质提示在缺少等级信息时会抛错；
  - 视图类型定义里漏了「私人 FM」，以及电台分类相关字段没进类型声明（运行正常，但类型检查一直报错）。

## 四、没有变的

下载、听书电台、在线收音机、米提亚主题、均衡器、可视化、语音转文字、私人 FM、桌面歌词九宫格/透明背景——全部保留，功能一个没删。
