# v2.2.9 · 桌面歌词，想摆哪就摆哪

**一句话**：桌面歌词现在能贴到屏幕九个位置、文字可以左中右对齐，背景还能彻底透明，只剩歌词浮在壁纸上。

## 这次更新，你能感受到什么？

- **贴到屏幕任意角落**：设置 → 桌面歌词，九宫格点一下，歌词立刻贴到 左上 / 上中 / 右上 / 左中 / 居中 / 右中 / 左下 / 下中 / 右下。歌词窗没开的话点一下就顺手打开，当场能看到位置。
- **想拖也行**：鼠标按住歌词窗随便拖，拖完设置里就不再显示某个预设格子（因为已经是自由位置了）。
- **文字左中右对齐**：长句靠左看、短句居中，按习惯调。
- **背景可以完全消失**：一个 0–100% 的滑块，拉到 0 就连边框、投影、毛玻璃一起收掉，只剩歌词漂在壁纸上。歌词窗工具栏也新增了一个 ◐ 按钮，点一下在「清晰 → 半透明 → 完全隐藏」之间循环。
- **透明了也看得清**：打开「文字描边」，白字压在亮壁纸、照片、网页上都认得出来；没唱到的字会自动提亮一档。
- 原来的字号、颜色、锁定、尺寸切换、拖动都还在，没有改动。

## 参考了哪些做法

翻了一圈主流桌面歌词的设置项，常见的就三类：位置（贴边/锁定）、样式（字号/颜色/对齐）、背景（透明度/模糊）。这次把位置和背景补齐，并且比它们多给了一个「完全隐藏背景」的彻底选项——很多播放器最低只能到 20% 左右。

## 顺带修掉的一个显示问题

给歌词加描边时踩到一个渲染坑：高亮行用的是「渐变裁剪到文字」的方式上色，如果同时继承 `text-shadow`，整行文字会变成镂空，只剩一圈黑边。现在把阴影只加在非高亮行，高亮行用投影描边，颜色和描边都正常。

## 验证

- 九宫格：点「左上」后窗口坐标变为 (28,28)，点「下」回到屏幕底部居中
- 背景：85% → 50% → 0%，背景 alpha 依次为 0.53 / 0.31 / 无（`background: none`、边框透明、投影消失）
- 对齐：左 / 中 / 右切换后歌词容器对齐方式依次为 flex-start / center / flex-end
- 描边：开启后高亮行仍是粉色实心 + 黑色描边（放大 4 倍截图确认），未高亮行带阴影
- 歌词窗未打开时点九宫格会自动打开并定位
- 三种布局 × 全部视图冒烟通过，**0 条控制台报错**
