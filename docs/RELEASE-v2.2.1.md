- 完整条款见仓库根目录 [LICENSE](https://github.com/lanmeiawa/yiyunmusic/blob/main/LICENSE)。

## 文案调整

- README 与首次启动提示不再强调"非官方 / 非公开接口"这类说法，改成更平实的描述：
  - 说明这是一个独立开发的播放器，账号、歌单与收藏都跟账号走；
  - 播放效果取决于账号权益和网络状况，遇到卡顿重试或换个音质即可；
  - 版权归原作者与平台，喜欢的话在官方平台收听或开通会员是最好的支持。
- 「免责声明」统一改为「关于本项目 / 使用须知」。
