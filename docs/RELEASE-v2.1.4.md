# v2.1.4 · 收音机播放修复 + 实时转文字真正可用

**一句话**：大批原本播不了的电台现在能放了，收音机的实时转文字也能逐句出字了。

## 在线收音机

- **支持 HLS 电台（最大头）**：国内央广、CCTV 伴音、喜马拉雅、凤凰等大量电台给的是 `.m3u8` 流，浏览器内核原生不支持，以前点了必失败。现在内置 HLS 播放内核，并把播放列表和分片都改写成走本地代理，绕开跨域限制。
- **三级兜底**：直连 → 本地代理 → 探测真实类型（HLS / 被 `.pls`、`.m3u` 包了一层）后重试；全部失败才提示，并且会说清是超时还是地区限制。
- **按国家筛选修复**：界面传的是「中国」这种名称，接口只认 `CN` 这种代码，以前等于筛不到；现在会自动转换。
- **国家 / 风格列表排序**：按电台数量从多到少排，常用项排在前面，不用再翻一堆冷门国家。
- **不再请求 ICY 元数据**：以前代理请求了元数据，上游会把信息块插进音频字节，播放器直接解不出来。

## 实时转文字

两个致命 bug，导致以前**永远出不来字**：

1. **词表路径放错层**：`tokens` 必须放在 `modelConfig` 顶层，之前塞进了 `senseVoice` 子对象里，底层直接忽略——等于没有词表。
2. **识别接口参数传错**：`acceptWaveform(sampleRate, samples)` 是两个位置参数，之前传的是对象，每次都抛异常，又被 `catch` 静默吞掉。

修复后实测：CNR-1 中国之声，每 4 秒输出一句，识别准确、标点正常。识别失败会提示具体原因，不再静默。

## 界面

- **沉浸布局侧栏不再「消失」**：收起时是 68px 图标条，鼠标移上去自动展开成 208px，导航文字、歌单、设置入口都在。
- **折叠侧栏同样支持悬停展开**，折叠后不会找不到入口。
- **电台页对齐**：标题、标签页、卡片网格左边缘统一，不再一处缩进一处贴边。

## 说明

- 语音模型仍是可选下载（约 230MB），已下载的用户直接就能用，无需重新下载。
- 少数电台本身已下线或限制地区，这类会给出提示而不是一直转圈。
