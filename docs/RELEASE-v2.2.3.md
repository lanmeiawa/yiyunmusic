## 协议：PolyForm 非商业 → MIT

- 改代码、二次开发、商用、打包送朋友，都可以，保留版权声明就行。
- 为什么换回来：非商业许可是想保护项目，但确实不够友好——连自己人想二次开发都要先来问一句，太见外了。MIT 大家都熟，省事。
- 小彩蛋：v2.2.1 那版非商业许可存活了大约两天，喜提「本项目寿命最短条款」。
