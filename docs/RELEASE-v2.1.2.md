# yiyunmusic v2.1.2 更新说明

> 小版本，修两个切换布局和布局切换后遇到的显示问题。

## 1. 杂志 / 沉浸布局下找不到「个性化设置」

之前切到**杂志布局**后，侧栏变成了顶部横向导航，但「个性化设置」的入口跟着整个底部区一起被藏起来了，结果就没法进设置页了。沉浸布局下入口也只剩一个图标、不好认。

这次修好了：

- 杂志布局把设置入口保留在横向导航里，随时能点进设置
- 三种布局下设置入口都在，切换布局不会「把自己锁在外面」

## 2. 个人中心的「我的歌单」空白

之前进个人中心，有时「我的歌单」是空的——因为歌单只依赖登录那一刻加载，如果当时接口慢、失败，或你刚登录，这里就一直空着。

这次改成：**每次进入个人中心都会主动重新拉一次歌单**，保证这里显示你的真实歌单，不再空白。
