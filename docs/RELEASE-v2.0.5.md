# yiyunmusic v2.0.5 更新说明

> 这次更新，你能感受到什么？—— 就一件事，用大白话讲。

## 1. 切换音质后，右下角的标签马上跟上

之前有个小毛病：你在右下角把音质从「极高」调成「无损」，弹窗里提示已经切换了，但按钮上那个小小的音质标签还是显示「极高」，要等歌曲重新加载完才慢慢变过来；有时候加载失败，它就一直停在旧档位，看着特别别扭。

这次修好了：

- 你一点选新音质，按钮上的标签**立刻**变成你选的那一档，不用再等
- 如果网易云那边把你选的「无损」实际降级成了「极高」，等真实音源返回后标签会再自动修正成实际情况，不会骗你

一句话：**点了就变，变了是真的。**
