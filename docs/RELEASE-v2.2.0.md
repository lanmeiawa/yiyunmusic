# v2.2.0 · 语音转文字支持多模型，中文更准

**一句话**：语音转文字现在有三种模型可选——中文专用、通用多语种、轻量快速，中文精度明显提升。

## 三种模型，按需选择

| 模型 | 体积 | 特点 |
| --- | --- | --- |
| **中文专用**（Paraformer） | 232MB | 中文最准，适合新闻、播客、访谈；输出不带标点 |
| **通用多语种**（SenseVoice） | 228MB | 中英日韩粤混说都能识别，自动补标点 |
| **轻量快速**（Paraformer-small） | 78MB | 体积最小、速度约为大模型 3–4 倍，适合低配电脑 |

- 可以**同时安装多个**，随时切换；下载完成会自动设为当前模型。
- 删除当前模型时会自动切到其他已安装模型，不会出现"没有模型可用"。
- 旧版本已下载的模型会**自动迁移**为「通用多语种」，不用重新下载。

## 中文精度实测

同一段中文语音：

- 通用多语种：`开饭时间早上9点至下午5点。`（把"开放"听成"开饭"）
- 中文专用：`开放时间早上九点至下午五点` ✅
- 轻量快速：`开放时间早上九点至下午五点` ✅

## 识别链路优化

- **重采样改进**：抓取 PCM 时由"按步长抽点"改为窗口均值抽取（简易低通），减少高频混叠，喂给模型的音频更干净。
- **识别器释放**：切换 / 删除模型时显式释放旧的 WASM 识别器，反复切换不会让内存持续上涨。
- **切换安全**：指定不存在的模型 ID 时只会返回失败，不会误删或误切当前模型。

## 安装与下载

- 安装时选择"下载语音模型"，默认下载**中文专用**模型；首次启动自动从国内镜像下载，支持断点续传。
- 已在设置里下载过模型的用户，升级后直接可用。
