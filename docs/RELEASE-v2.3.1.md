# yiyunmusic v2.3.1 · 这次更新，你能感受到什么？

**一句话**：桌面歌词的工具栏会自己收起来了，而且终于是真的透明；顺手把一个会把你在网络抖动时误登出的问题也修了。

---

## 一、桌面歌词工具栏：会自己收，也是真透明

如果你用透明背景的桌面歌词，之前大概见过这样的画面——鼠标划过去之后，顶上就一直挂着一条深色条，上面还有一排灰底方块按钮，压在壁纸上特别出戏。

原因有两个：
- 工具栏只会在「离开工具栏」时收起，鼠标从歌词区划过时它弹出来就再也不走了；
- 为了让桌面歌词窗口更轻（v2.3.0 把它拆成了独立窗口），它不再加载主界面的全局样式，**按钮的基础重置跟着丢了**，于是退化成系统默认的灰底 3D 按钮。

这次都改了：

- **自动收起**：鼠标进入窗口时出现，停止操作 2 秒后自动淡出；鼠标停在工具栏上时保持显示，移出窗口立即收起。
- **不再挡点击**：收起状态下工具栏不接收鼠标事件，不会挡住歌词区域的点击。
- **真透明**：按钮去掉灰底与边框，只剩图标；背景设为「完全隐藏」时，整条工具栏（含顶部渐变、拖动把手底色）一起变透明，不留任何色块。
- **浅色壁纸也看得清**：无背景时图标与歌名改为纯白 + 描边阴影，压在亮色照片上依然清晰。

## 二、登录状态更稳了

之前有个隐患：拉取用户资料时，只要接口返回一次空结果（风控、网络抖动都会），程序就直接把你登出。现在会再用另一个接口复核一次，两处都拿不到才判定未登录。

## 三、没有变的

下载、听书电台、在线收音机、主题、均衡器、可视化、语音转文字、私人 FM、歌词九宫格/对齐/字号/颜色——全部保留。

## 验证方式

- 工具栏计算样式：按钮 `background: rgba(0,0,0,0)`、`border: none`；无背景时工具栏 `background: none`
- 自动隐藏：触发鼠标移动后 200ms 显示，2.8 秒后恢复到 `opacity: 0`
- 彩色壁纸下截图确认：歌名与 9 个按钮全部可辨，无灰底、无边框、无残留色块
- 三种布局 × 全部视图冒烟，0 条控制台报错
