# v2.1.3 · 修复非经典布局底部的空白带

**一句话**：沉浸和杂志布局下，右侧内容区底部那条多余空白没有了。

## 修了什么

- **底部空白带**：v2.1.1 做布局改版时，给主内容区加了 120px / 130px 的底部内边距（原本是想给「悬浮播放器」留位置），但播放器一直是固定在窗口底部的独立栏，这段预留就变成了纯空白。表现为除经典布局外，右侧内容区底部总有一条无内容的空白带，设置页、个人中心这类自身滚动的页面尤其明显。
- **重复内边距**：各页面本身已有 36px 左右的内边距，主内容区再叠一层会导致左右留白过大、内容偏窄。现在统一由页面自身控制间距。
- **沉浸布局背景**：主内容区不再强制透明，恢复跟随主题背景，避免与窗口底色出现色差、看起来像「空了一块」。

## 布局现在的样子

- **经典**：左侧栏 + 主区 + 底部播放器
- **沉浸**：68px 图标侧栏 + 内容居中限宽 1180px + 玻璃质感播放器
- **杂志**：侧栏变成顶部横向导航 + 全宽大图卡片流

三种布局的内容区都完整铺到播放器上方，不再有空白带。

## 验证

- 三种布局 × 9 个主视图（发现 / 歌词 / 私人FM / 最近播放 / 本地 / 听书 / 在线收音机 / 个人主页 / 设置）逐个切换，全部正常渲染，无控制台报错。
- 三种布局下设置入口均可见、可点击。
- 内容区底部内边距统一为 0，页面底部与播放器之间间隙为 0。
